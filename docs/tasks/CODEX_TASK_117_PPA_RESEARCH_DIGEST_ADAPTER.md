# TASK 117 — PPA repository-evidence adapter for the research ephemeral digest

## Scope

T0/offline only. No PDF/Drive/network/OCR read is performed. The adapter consumes only exact, blob-pinned repository evidence already produced by TASK 107, TASK 041 and TASK 049.

## Why this adapter exists

TASK 116 defined the generic research stomach. TASK 117 proves that planning evidence can enter that stomach without being silently upgraded into financial execution.

Two packets are emitted:

- PPA 2022–2025 — exact TASK 107 page-23 primary excerpt;
- PPA 2026–2029 — deterministic serialization of directly validated TASK 041 Program 2001 / indicator / selected-action fields.

The representation boundary is explicit. TASK 117 is not a raw-PDF parser.

## Monetary rule

PPA projected/planned values are intentionally not mapped into TASK 116 amount observations. They are neither LOA authorization nor commitment/liquidation/payment.

That means a PPA may supply policy/planning signals and stable planning/accounting keys while still producing zero financial-identity candidates.

## Expected research behavior

- 2022–2025: the indicator signal is rediscovered; stable accounting link and execution amount remain missing.
- 2026–2029: the indicator signal plus Program 2001/unit keys are rediscovered; execution amount/stage remains missing.
- generic actions remain non-EITI-specific.
- TASK 049's 27-row no-match remains a bounded search result and never proves absence of EITI spending.

## Effects

Zero network, Drive, OCR, persistence, queue, StateRegistry, serving, publication, retry, recurrence or schedule.
