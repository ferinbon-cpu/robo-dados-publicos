**QUERY_LIKE_DELIMITED_WITHOUT_SAFE_KEYS**

A named query-string contract is not proven.

**DESPESAS / ACCOUNTING LAYER IDENTITY = NOT PROVEN**

## Scientific consequence

The next useful step is no longer deeper parsing by guessing.

The safe next route is to correlate each automatically generated LayerInfo envelope to the browser DOM container that receives it, using one-way hashes or other non-value structural bindings. Only then can the robot inspect structural DOM/accessibility metadata for a layer identity.

Visible labels, interactive queries and any lookup of Empenho 3286-2026 remain separately gated.
