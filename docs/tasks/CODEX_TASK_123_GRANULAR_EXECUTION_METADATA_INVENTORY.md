# TASK 123 — metadata-only granular execution inventory

This task consumes TASK 122's directed acquisition objective and searches only Google Drive filename metadata for likely granular accounting-execution candidates.

The search is bounded to eight filename terms and one metadata page per term. No file content may be hydrated or opened.

The inventory may rank candidates only from observed filename/title and basic metadata. A filename can justify a next probe, never a substantive claim about the file's contents.

Known insufficient sources are excluded from recommendation: the aggregate May expense balancete, the SIOPE-MAVS reporting-bucket report, and monthly FUNDEB cash/receipt files.

Any future content read requires a separate gate after the metadata inventory is closed.
