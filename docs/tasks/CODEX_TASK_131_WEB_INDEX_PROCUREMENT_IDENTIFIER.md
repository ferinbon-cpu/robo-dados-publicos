TASK 131 therefore uses search-indexed text only to recover a stable administrative identifier for the selected 2026 Educação Integral oficineiro procurement.

It may select a future exact lookup, but it cannot establish financial identity, transaction identity, supplier linkage or expenditure attribution.

No PNCP weak-term join is permitted here.
