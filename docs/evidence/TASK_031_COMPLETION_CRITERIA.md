# TASK 031 completion criteria

TASK 031 is complete when:

1. the source-first policy is machine-readable;
2. the three exact JOM edition URLs are pinned;
3. search-engine indexing is explicitly prohibited as an extraction source;
4. full equivalence with standalone Prefeitura PDFs is explicitly not a prerequisite for Jornal extraction;
5. custody/hash/readback are explicit prerequisites before parsing;
6. all layer promotions and live acquisition remain false;
7. unit tests fail closed on unsafe mutations, source drift or premature custody claims.

The task does not download, hash, store or parse the JOM PDFs.
